# Código de conduta

Este é um projeto educacional de acolhimento. Espera-se que participantes tratem diferenças de conhecimento, idade, origem, identidade, deficiência e experiência tecnológica com respeito.

Não serão aceitos assédio, discriminação, exposição de dados pessoais, humilhação de iniciantes ou linguagem deliberadamente hostil. Críticas devem se concentrar no conteúdo, no código e na experiência, nunca na dignidade das pessoas.
