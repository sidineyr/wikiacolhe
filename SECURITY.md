# Segurança e privacidade

O WikiAcolhe não possui contas, banco de dados ou processamento de informações pessoais. Preferências de idioma e progresso ficam apenas no armazenamento local do navegador.

Para relatar uma vulnerabilidade, comunique o mantenedor antes de publicar detalhes que possam expor visitantes. Não inclua dados pessoais, credenciais ou informações sensíveis no relato.
